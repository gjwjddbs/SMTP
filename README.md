# SMTP

## 목표

- 프로젝트의 목표는 파이썬의 SMTP 라이브러리를 이용한 메일 전송 및 메일 내용에서 중요정보(ex. 주석, 주민등록번호) 탐지 기능을 구현하는 것입니다
